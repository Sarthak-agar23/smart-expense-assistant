# Smart Expense & CSV Assistant

A beginner-friendly Python project that cleans expense data and generates useful summaries.

## Features

- Reads expense records from a CSV file
- Checks for missing or invalid data
- Removes duplicate records
- Calculates total expenses
- Summarises expenses by category
- Saves cleaned records to a new CSV file

## Technologies Used

- Python 3
- CSV file handling
- Data validation

## How to Run

1. Install Python 3.
2. Download this repository to your computer.
3. Open a terminal in the project folder.
4. Run `python main.py`.

## Sample Data

The project uses fictional expense records for testing and demonstration.
